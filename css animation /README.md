# CSS Animation – Bell

A pure HTML/CSS bell animation with a toggleable bulb glow. Click the bell (or the **Notify Me** button) to light it up; click again to switch it back off.

## Demo

Open `index.html` in any modern browser.

## Features

- Pure CSS — no frameworks
- Bell swings on a gentle pendulum
- Inner bulb + floor puddle glow when toggled on
- Click the bell **or** the button to toggle the light

## Files

- `index.html` — markup + inline CSS + tiny JS toggle
